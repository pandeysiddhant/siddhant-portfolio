## Problem
Manual deployment of Azure Data Factory (ADF) pipelines via the UI caused **configuration drift**, lacked **version control** for pipeline JSON definitions, and created a **bottleneck** during releases. Rollbacks were error-prone and auditing changes was impossible.

## Solution Architecture
I developed a **metadata-driven automation framework** running on **Azure Databricks** that treats ADF resources as code.

### Key Components
1.  **JSON Definitions**: All ADF artifacts (Pipelines, Datasets, Linked Services, Triggers) stored as parameterized JSON files in Git.
2.  **Databricks Orchestrator**: A Python notebook triggered by Jenkins on PR merge.
3.  **Authentication**: **MSAL (Microsoft Authentication Library)** using Service Principal (Client Credentials Flow) for secure, non-interactive token acquisition.
4.  **Idempotent REST Client**: Handles `PUT` (Create/Update), `PATCH` (Partial Update), `GET` (Existence Check), `DELETE` (Cleanup). Implements **Exponential Backoff** for API throttling (429 errors).
5.  **Dependency Resolution**: Topological sort of resources (Linked Services → Datasets → Pipelines → Triggers) to ensure deployment order.

## Technical Highlights
- **Parameterization**: Used `databricks.widgets` to inject environment-specific values (Key Vault names, Storage Accounts) into JSON payloads at runtime.
- **Schema Validation**: Validated JSON payloads against ADF REST API schemas before submission to catch errors early.
- **Drift Detection**: Scheduled job compares Live ADF state (via `GET` API) vs Git state; alerts on mismatch.
- **CI/CD Integration**: Jenkins pipeline stage: `Lint JSON` → `Unit Test Python Client` → `Deploy to Dev` → `Manual Approval` → `Deploy to Prod`.

app = ConfidentialClientApplication(

    client_credential=client_secret
)
token = app.acquire_token_for_client(scopes=["https://management.azure.com/.default"])['access_token']
headers = {"Authorization": f"Bearer {token}", "Content-Type": "application/json"}

# 2. Deploy Pipeline (Idempotent PUT)
def deploy_pipeline(resource_group, factory_name, pipeline_name, payload):
    url = f"https://management.azure.com/subscriptions/{sub_id}/resourceGroups/{resource_group}/providers/Microsoft.DataFactory/factories/{factory_name}/pipelines/{pipeline_name}?api-version=2018-06-01"
    resp = requests.put(url, headers=headers, json=payload)
    resp.raise_for_status() # Handles 4xx/5xx
    return resp.json()
